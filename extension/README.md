# ⚡ Yahoo! Auction to Flea Market Reseller (Helium 10 Style Chrome Extension)

Yeh Google Chrome extension hai jo direct **Yahoo! Auctions (`auctions.yahoo.co.jp`)** ke opar live run karti hai bilkul **Helium 10 (Amazon X-Ray)** ki tarah!

---

## 🚀 Features (Helium 10 Style)

1. **⚡ Yahoo Arbitrage X-Ray (Floating Button & Slide-Over Modal):**
   - Jab aap Yahoo Auctions search ya category browse kar rahe honge, bottom-right par floating **"⚡ Yahoo X-Ray"** button aayega.
   - Click karne par page ke tamam 50 products ka Helium 10 style table khul jayega:
     - Buy Price, Target Flea Price, Net Profit (Green), Margin %, Box Status, Condition, Turnaround Speed.
     - 1-Click Filters: "🔥 Profitable Only", "📦 With Box", "🚫 Hide Junk".
     - 1-Click "📥 Save to Inventory" button.
     - "📊 Export CSV" button.

2. **🏷️ Inline Product Badges:**
   - Yahoo Auctions search result ke har card ke neechay automatic badge show hota hai:
     - 💰 Net Profit (e.g. `+¥8,500 (+35%)`)
     - 🎯 Real Flea Market Target Price
     - 📦 Box Status (`箱付き` vs `本体のみ`)
     - ⚠️ Junk Alert (`ジャンク / 画面割れ`)
     - 🔗 Direct Link to live sold listings on PayPay Flea Market!

3. **🔍 Single Listing Inspector:**
   - Kisi bhi auction listing page (`page.auctions.yahoo.co.jp/jp/auction/...`) par bid box ke barabar me **Reseller Profit Card** show hota hai with **Max Safe Bid Recommendation**!

4. **🧩 Chrome Toolbar Popup:**
   - Instant Profit Calculator.
   - Category ROI Margin Guide.
   - 1-Click X-Ray launcher.

---

## 🛠️ Chrome Me Install Karne Ka Tareeqa (Sirf 15 Seconds):

1. **Google Chrome** open karein.
2. Address bar me type karein: `chrome://extensions` aur Enter dabayein.
3. Top-Right corner par **"Developer mode"** ka toggle switch **ON** karein.
4. Top-Left corner par **"Load unpacked"** button par click karein.
5. Folder select karein:
   `C:\Users\Sami\yahoo-fleamarket-assistant\extension`
6. **Bas! Extension install ho gayi!** 🎉

Ab [Yahoo! Auctions](https://auctions.yahoo.co.jp) par jayein aur search karein—Helium 10 style X-Ray foran active ho jayega!
